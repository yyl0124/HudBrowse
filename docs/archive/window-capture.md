# 窗口捕获功能使用说明

## ✅ 已修复的问题

### 1. **窗口捕获流程优化**
- ❌ 旧方式：点击捕获按钮 → 移动鼠标 → 点击确认（不好用）
- ✅ 新方式：点击"捕获窗口"按钮 → 自动显示所有打开的窗口列表 → 点击选择

### 2. **AddUrlDialog 组件适配**
- ✅ 自动识别窗口类型（`type === 'window'`）
- ✅ 窗口类型会显示窗口信息卡片，不显示URL输入框
- ✅ 窗口类型不验证URL，只验证名称和快捷键
- ✅ 保存时保留 `windowInfo` 信息

### 3. **快捷键触发逻辑完善**
- ✅ 区分网页类型和窗口类型
- ✅ 窗口类型触发时调用 `toggleCapturedWindow`
- ✅ 网页类型触发时调用原有的 `toggle_or_create_window`

## 🚀 使用流程

### 步骤 1：捕获窗口

1. 打开应用，进入"网址管理"页面
2. 点击右上角的 **"🖥️ 捕获窗口"** 按钮
3. 弹出窗口列表对话框，显示所有当前打开的程序窗口
4. 可以使用搜索框快速筛选（搜索标题或路径）
5. 点击任意窗口进入下一步

### 步骤 2：设置快捷键

1. 自动打开"编辑窗口"对话框
2. 显示窗口信息卡片（标题、路径、进程ID）
3. 修改窗口名称（可选，默认使用窗口标题）
4. 点击"录制"按钮，按下你想要的组合键（如 `Ctrl+Shift+W`）
5. 点击"保存"

### 步骤 3：使用快捷键

- 按下设置的快捷键 → 窗口显示
- 再按一次 → 窗口隐藏
- 支持设置透明度、置顶等功能

## 🎯 功能特点

### 窗口代理模式
- ✅ 不嵌入窗口，通过Windows API直接控制
- ✅ 兼容性好，支持大部分桌面程序
- ✅ 支持透明度、置顶、位置记忆

### 智能窗口查找
- ✅ 如果窗口被关闭，下次触发时自动查找同名进程
- ✅ 通过进程路径识别窗口
- ✅ 友好的错误提示

### 完整的设置支持
- ✅ 透明度调节（0-100%）
- ✅ 窗口置顶
- ✅ 位置和大小记忆
- ✅ 支持全局设置和独立设置

---

## ⚠️ 注意事项

### 管理员权限
- 如果要控制以管理员权限运行的程序，**HudBrowse 本身也需要以管理员权限运行**
- 例如：控制 任务管理器、注册表编辑器 等系统工具

### 兼容性
- ✅ **支持大部分程序**：记事本、计算器、微信、QQ、VS Code、Chrome 等
- ⚠️ **部分限制**：
  - 游戏（可能有反作弊检测）
  - 安全软件（可能拦截窗口操作）
  - UWP应用（Windows Store应用）

### 窗口失效处理
- 如果窗口被关闭后再打开，快捷键会自动查找新窗口
- 如果找不到窗口，会显示友好的错误提示

## 🔧 技术实现

### 前端（TypeScript）
- `WindowCapture.tsx`: 窗口选择界面
- `AddUrlDialog.tsx`: 支持窗口类型的编辑对话框
- `useWindowManager.ts`: 窗口控制逻辑
- `useHotkeyManager.ts`: 快捷键区分处理

### 后端（Rust）
- `window_capture.rs`: Windows API 封装
  - `enumerate_windows()`: 枚举所有可见窗口
  - `toggle_captured_window()`: 显示/隐藏窗口
  - `set_captured_window_opacity()`: 设置透明度
  - `set_captured_window_always_on_top()`: 设置置顶
  - `is_window_alive()`: 检查窗口是否存在

### 数据结构
```typescript
interface UrlConfig {
  type: 'url' | 'window';  // 区分类型
  windowInfo?: {           // 窗口信息
    hwnd: number;         // 窗口句柄
    title: string;        // 窗口标题
    exePath: string;      // 进程路径
    processId: number;    // 进程ID
    className: string;    // 窗口类名
  };
  // ... 其他字段
}
```

## 🐛 已知问题和限制

1. **非Windows平台**：窗口捕获功能仅支持Windows
2. **首次捕获**：需要先打开目标程序，才能在列表中看到
3. **多窗口程序**：如果一个程序打开多个窗口（如Chrome多个标签），会显示所有窗口，需要手动选择
