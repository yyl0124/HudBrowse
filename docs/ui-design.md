# HudBrowse Island Workspace

## 参考与方向

参考项目：[Modivue](https://github.com/systemoutprintlnhelloworld/Modivue)。提取其透明原生窗口、状态环、极简/展开形态和按需详情的交互思路，保留 HudBrowse 的目标与配置模型。不迁移参考项目的业务逻辑或框架，不复制其图片、图标和源码。

使用 `design-style` 的动态风格流程，以及 `gsap-react`、`gsap-core`、`gsap-performance` 的 React 生命周期、动效和性能规范。

风格：Island Workspace，Apple HIG / Liquid Glass 的形态语法，加上桌面工具的信息密度。

- 字体：Segoe UI Variable / Segoe UI / Microsoft YaHei UI；数据使用 Cascadia Code / Consolas。
- 标题固定 27px，移动端 23px；不用视口宽度计算字号，不使用负字距。
- 取消应用侧边栏和旧卡片布局；顶部状态岛集中导航、窗口控制，主体为目标库与无框详情栏。
- 标题与工作台共用 SVG 轮廓，以 20px 内凹接缝圆角平滑连接。品牌标识使用用户提供的 `public/hudbrowse.png`；窗口轮廓仍由代码绘制。
- 标题栏、浏览器页签、托盘与 EXE 图标统一使用最新品牌素材，`scripts/sync-icons.py` 从原图生成桌面 PNG 及多尺寸 ICO。
- 首页宣传语为“常用窗口，随手即达”。移除英文装饰标签、标题斜杠及列表底部的重复统计，只保留必要的中文信息。
- 网站优先请求 `/favicon.ico`，失败时由原生服务解析网页声明的图标，不经过第三方图标服务；桌面程序通过窗口图标、窗口类图标、可执行文件依次提取。图标不可用时显示名称首字，避免所有目标使用相同占位图。
- 用实际目标和原生运行状态计算数量、显示状态、尺寸等信息，不向生产代码注入演示记录。

## 形态与原生行为

- 展开态：1120 × 760 初始逻辑尺寸，最低 760 × 560；顶部标题与主体相连，标题两侧肩部透明。
- 极简态：440 × 100 的独立胶囊，置顶，最多显示三个目标入口和实际活跃数量；展开后恢复原尺寸，自动限制在显示器工作区内。
- 迷你态不卸载工作台，保留搜索、筛选、选中目标和表单状态。
- `src/utils/shellShape.ts` 同时生成 SVG 绘制和 Win32 裁剪所用的点；原生服务将 WebView 客户区坐标映射到整个窗口坐标，并适配 DPI，透明肩部与圆角不占鼠标命中区域。
- 整条自定义标题栏的非按钮区域均支持拖动；保留最小化、最大化/还原和关闭，关闭行为保持原有托盘策略。
- 右下角提供原生缩放手柄。只改变管理主窗口，不改变用户网址浮窗的原生标题栏或第三方桌面窗口装饰。
- 桌面端真正透明；独立浏览器展示主题背景，并明确显示原生服务未连接状态。

## 布局与流程

- 目标库支持类型、分类、名称/网址/快捷键搜索、活跃优先及名称排序。
- 选中目标详情显示生效设置、实际尺寸和快捷键；显示/隐藏与配置修改继续使用已有共享调度服务。
- 小屏幕取消详情栏，行内保留设置、编辑、重连和直接删除；删除仍需确认。网页右键菜单仅保留导航、刷新及站点数据操作。
- 分类与排序全部采用自定义下拉框，支持方向键、Home/End、Enter 和 Escape；详情栏隐藏滚动条，仍支持滚轮与触控板滚动。
- 设置分为默认窗口、应用和外观三个视图，独立配置不受全局修改覆盖。
- 表单、窗口选择、设置和删除确认共用带焦点约束的对话框；内容区域独立滚动以适配最低窗口高度。

## 动效与验证

- GSAP 动效以 opacity / transform 为主；scoped `useGSAP` 自动清理，`matchMedia` 遵循系统减少动态效果。
- 导航、目标类型和设置标签共享滑动高亮；列表筛选、排序与详情切换使用 240ms 淡入和轻微位移。列表仅对可视条目执行动效，后台状态轮询不重复触发。
- 按钮、开关、主题、下拉框、窗口状态和表单反馈使用 140–280ms 过渡。弹窗与下拉框退出保留 140ms 淡出，退出内容立即停止接收鼠标和键盘事件；捕获切换到编辑表单时保持新表单焦点。
- 动效回归测试覆盖连续反向切换、减少动态效果、弹窗关闭、焦点保持和键盘导航。
- 单元测试继续覆盖原有数据和操作契约。
- Playwright 增加目标库筛选、详情、迷你态保留状态、主题切换、应用选项和删除流程，以及多尺寸截图。测试替身仅存在于测试代码。
- 贴边隐藏和展开由单个窗口监视线程驱动 220ms 缓动，动画中鼠标返回可从当前位置反向展开，停止监视会恢复窗口位置。
- 前端测试校验共享轮廓与原生测试夹具一致；显式原生冒烟测试验证当前桌面 DPI 下的透明主窗口、迷你态尺寸、展开恢复及控件/接缝的实际命中区域。原生单元测试还覆盖图标透明通道、动画中间位置及反向插值。
- 多显示器混合 DPI、系统动画设置及不同显卡/WebView2 版本仍需对应环境实机验收。

## 1.0.8 细节优化

- 品牌资源采用 `public/hudbrowse-small.png`（314×314），由脚本生成 16–256px 多分辨率 ICO；标题栏以固定布局盒放大图标，不影响文字行高和按钮位置。
- 显示状态使用睁眼，隐藏状态使用划线眼睛；按钮提示仍描述点击后的操作。
- 详情切换仅对内部内容执行动效，工作台外层不参与滚动，列表与详情独立滚动。
- 详情在下方仍有内容时显示可点击的向下箭头，滚动到底或内容无需滚动时隐藏，支持键盘和减少动态效果设置。
- 应用设置采用三列等宽卡片，窄屏自动改为单列。

## 1.0.10 灵动岛交互

- 原生 ICO 直接采用 `public/bitbug_favicon.ico`，不重新编码；托盘 PNG 由该 ICO 无缩放解码，前端品牌图继续使用 285px PNG。
- Tauri 1.x 的代码生成器从 ICO 的第一帧创建运行时窗口图标。旧多尺寸 ICO 首帧为 16px，本次源文件为单帧 64px，编译产物逐像素验证一致。
- 主界面收起时向标题栏方向压缩并淡出；原生窗口尺寸在透明阶段切换，随后新界面展开淡入。GSAP 清理临时样式，切换中避免重复操作，失败时恢复原界面，并遵循减少动态效果设置。
- 灵动岛独立启用左右贴边收纳，移开鼠标 280ms 后用 220ms 缓动收回，保留 36 个逻辑像素的半圆提示。半圆按 DPI 缩放，顶部和底部不触发收纳；悬停半圆滑出，拖离边缘取消吸附。
- 使用独立原生监视模块；展开、托盘关闭与退出时取消监视，已排队的位置更新会检查取消状态，避免移动展开后的主窗口。
- 原生测试验证当前桌面 DPI 下的左右半圆暴露宽度、展开后停止移动和窗口图标帧。逻辑测试另覆盖负屏幕坐标、自定义 DPI、悬停反向移动及半圆曲线处保持展开。


## 1.0.11 贴边容错与岛内图标

- 贴边识别同时覆盖靠近边缘及跨过边缘：灵动岛有一部分在屏幕外时，松开并移开鼠标后直接从当前位置收纳到半圆，不先弹回屏幕内。拖动过程中不吸附，完全离开该工作区的窗口不误判为贴边。
- 灵动岛目标图标占满 36px 点击区域，去掉双层圆框、底色和图片内边距；保留加载失败时的文字替代及按钮状态语义。
- 托盘仍使用用户 ICO 无缩放解码的 64px PNG；逐像素比对一致。没有发现旧图资源或小图放大问题，按用户要求保留现有图样。
- 回归覆盖左右两侧不同遮挡比例、负坐标与 DPI，以及真实 WebView2 窗口拖出约 20%、50%、85% 后的半圆暴露宽度。

## 1.0.12 图标层级

- 标题栏与灵动岛品牌 Logo 统一为 36px；移除缩放变换，保留标题栏原有高度。
- 灵动岛目标图像为 30px，外层 36px 点击区域保留一条 1px 圆角边框。显示状态使用主题色实线，隐藏状态使用灰色虚线；不叠加内圈或底色。

## 1.0.13 关闭行为

- 设置 → 应用增加“关闭时最小化到托盘”，默认开启以保持旧版行为。关闭开关后，主窗口的关闭按钮和 Alt+F4 走原有退出清理流程：保存会话、停止监视、恢复捕获窗口后退出。
- 偏好持久保存，启动时同步到原生层，恢复默认设置时同步恢复。托盘图标关闭时，常驻模式退回最小化到任务栏，页面说明同步变化。
- 四项应用设置按两列等宽平铺，窄屏使用单列。

## 1.0.14 运行时修复与灵动岛导航

- 主标题栏通过 `request_main_close` 发送 WM_CLOSE，统一进入原生关闭请求逻辑。Tauri 1 的 `appWindow.close()` 会直接销毁窗口，不能依赖 CloseRequested 拦截它；原有纯前端 IPC 替身测试未覆盖这一点。
- 网页创建命令使用 Tauri 异步调度，避免在 WebView2 的同步 IPC 回调中创建新的 WebView 而阻塞消息循环。新增真实 IPC 测试验证页面 DOM 加载完成、命令返回和关闭控件。
- 捕获目标在显式显示/切换时尝试启动保存的 EXE，最长等待 20 秒重新绑定；程序已经运行时不重复启动，多候选仍交由用户选择。轮询和应用设置不触发启动。
- 灵动岛按持久化目标顺序展示，不再按可见状态重排。可拖拽排序，Alt+左右键也可调整位置。轨道一次显示三个图标，鼠标滚轮、触控板和触摸横向浏览其余目标，拖到边缘时自动滚动。
- 网页标题栏使用独立 Win32 子控件在原有 WebView 上方绘制，提供刷新、休眠/唤醒、最小化、最大化及关闭。网页布局预留标题栏高度，随尺寸和 DPI 更新，不注入网站 DOM，不增加 WebView 或渲染进程。
- 休眠隐藏页面控制器并调用 WebView2 TrySuspend，成功后保留网页会话和内存状态；失败则恢复页面并允许重试。唤醒按钮或快捷键通过 Resume 继续当前页面，不重新加载。此模式不是网页卸载，具体节省资源量取决于网站与 WebView2。

## 1.0.15 灵动岛输入修复

- 岛内排序改为 Pointer Events：超过 5px 移动后捕获指针，展示来源与放置位置；松开时一次性保存排序。Escape、失焦或移出轨道松开会取消，拖拽不触发目标点击。
- 关闭主窗口不使用的 Tauri 文件拖放接管，并禁止图标触发 HTML5 原生拖放，避免 Windows OLE 拖放模式导致岛内收不到 drop。
- 移除轨道的 scroll-snap，防止小幅 scrollLeft 增量被吸回原位置。使用非 passive wheel 监听器统一处理水平/垂直滚轮及像素/行/页单位；触摸保留原生横向滚动。
- 增加左右浏览按钮，可用鼠标逐组浏览目标。拖拽排序接近轨道边缘时按帧滚动，结束或取消时清理指针捕获和动画帧。
- 新增测试直接在真实 Tauri/WebView2 中加载生产 React 构建，通过 Windows SendInput 执行鼠标拖拽、细粒度滚轮与浏览按钮点击；使用隔离的配置和桌面操作替身，测试后恢复鼠标位置与前台窗口。


## 1.0.16 组合场景与四图标灵动岛

- 灵动岛保留 36px 品牌标识与 30px 目标图像，以 156px 轨道容纳四个 36px 图标容器；状态只保留圆点和数量。440px 窗口及 WebView2 缩放后的 400px 内容宽度均验证无遮挡。
- 新增场景类型，以 `memberIds` 保存有序引用，和网址/桌面目标共用排序及快捷键。场景不传入原生窗口管理器，不复制成员配置，也不参与原生会话恢复。
- “添加场景”位于捕获与网址入口之间，采用连贯按钮组、薄荷色桥接按钮和窗口/网页组合符号。沿用本文件 Island Workspace 动态设计规范，不引入另一套字体或颜色。
- 选择成员时显示顺序编号与启动顺序摘要；取消后重新勾选会移到队尾。场景图标展示前四个成员的组合，空场景使用图层符号。
- 执行前读取实时窗口状态，依次显示或隐藏成员；全显示时隐藏，全隐藏时唤醒，混合状态向多数统一，平票显示。最小化与未启动计入隐藏。失败继续后续成员，并汇总具体失败目标。
- 原生 `hide_target` 是幂等隐藏，不创建网页或启动程序；删除成员同步清理场景引用，删除场景保留成员。
- 提取共享快捷键录制组件；场景详情展示成员顺序与状态，不显示不适用的独立窗口设置。
- 验证包含状态组合/事务/存储/初始化单元测试、完整场景 UI 流程和实际 Win32 鼠标输入。截图使用隔离测试数据，图标由测试替身提供。

## 1.0.17 桌面程序生命周期修复

- 启动恢复仅恢复网页浮窗。桌面目标在启动时只连接已运行的窗口；快捷键、目标按钮和场景仍可主动唤醒程序。设置文案同步为“恢复上次可见网页”。
- 主动唤醒桌面程序通过现有 Windows 桌面 Shell 的 COM 接口执行，使程序脱离 HudBrowse 的进程树，不继承其启动句柄。保留原有路径校验、程序去重和窗口重连逻辑。
- 释放捕获只还原透明度、置顶和鼠标穿透等控制，并使被隐藏的窗口重新可见，不重放捕获瞬间的隐藏状态。用户在启动后关闭自己的程序时，不会被退出清理重新启动。
- “添加场景”改用单个 Layers 图标，横向内边距从 14px 收至 10px，图文间距缩至 5px，延续两侧入口之间的薄荷色按钮。
- 原生回归使用隔离的 WinForms 程序和临时目录：验证程序树、含中文/空格路径的启动，以及 HudBrowse 实际退出后目标进程和窗口仍存在；覆盖显示与隐藏两种状态。
