# 📁 图标文件说明

## 📌 必需文件（至少需要这个）

### icon.ico
- **用途**: Windows 应用图标（任务栏、窗口标题）
- **格式**: .ico 文件
- **推荐尺寸**: 256x256 或包含多个尺寸（16x16, 32x32, 48x48, 256x256）
- **状态**: ⚠️ **缺失 - 必须添加！**

---

## 🎨 可选文件（建议添加）

### icon.png
- **用途**: 通用图标，用于系统托盘
- **格式**: PNG 透明背景
- **推荐尺寸**: 512x512 或 1024x1024
- **状态**: 可选

### 32x32.png
- **用途**: 小图标
- **格式**: PNG
- **尺寸**: 32x32
- **状态**: 可选

### 128x128.png
- **用途**: 中等图标
- **格式**: PNG
- **尺寸**: 128x128
- **状态**: 可选

### 128x128@2x.png
- **用途**: 高清显示器用中等图标
- **格式**: PNG
- **尺寸**: 256x256（实际）
- **状态**: 可选

---

## 🛠️ 如何获取图标

### 方法 1: 在线生成（最简单）
1. 访问：https://www.favicon-generator.org/
2. 上传你的 PNG 图片
3. 下载生成的 `icon.ico`
4. 放入此目录

### 方法 2: 使用现成图标
1. 访问：https://icon-icons.com/
2. 搜索你想要的图标
3. 下载 ICO 格式
4. 重命名为 `icon.ico`
5. 放入此目录

### 方法 3: 使用 AI 生成
1. 使用 DALL-E、Midjourney 等生成图标
2. 使用在线工具转换为 ICO：https://convertio.co/png-ico/
3. 放入此目录

### 方法 4: 临时使用默认图标
如果暂时没有图标，可以：
1. 访问：https://via.placeholder.com/256.png
2. 右键保存图片
3. 使用 https://convertio.co/png-ico/ 转换为 ICO
4. 放入此目录

## ▶️ 放置图标后的下一步

将 `icon.ico` 文件放入此目录后，在项目根目录运行：

```powershell
npm run tauri:dev
```

应用就可以正常启动了！🚀

## 💡 提示

- 图标建议使用简洁、辨识度高的设计
- 背景最好是透明的
- 推荐使用浏览器相关的图标元素（如地球、窗口、浏览器图标等）
- 可以参考 Chrome、Edge 等浏览器的图标设计风格
