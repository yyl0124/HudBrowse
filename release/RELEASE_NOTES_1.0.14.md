# HudBrowse 1.0.14

修复：

- 开启“关闭时最小化到托盘”后点击叉号仍退出。原先调用的 Tauri 1 close API 直接销毁主窗口，现改走 WM_CLOSE / CloseRequested；托盘关闭时保留任务栏最小化兜底，退出模式仍执行正常清理。
- 快捷键打开网页时白屏且无法关闭。同步 IPC 回调内创建 WebView2 会阻塞消息处理，现将显示/切换命令移到后台调度。
- 捕获目标的程序未启动时，快捷键会尝试启动已记录的 EXE 并等待窗口重新绑定。不会在状态轮询时启动程序，不重复启动已运行的程序；路径失效、启动失败、超时或多个候选均返回明确提示。

新增：

- 灵动岛固定顺序，支持拖拽排序并保存，也支持 Alt+左右键调整位置。
- 岛内图标可以用鼠标滚轮、触控板或触摸横向浏览，访问三个之外的目标。
- 网页原生自绘标题栏：刷新、休眠/唤醒、最小化、最大化、关闭；拖拽空白处移动窗口。
- 网页休眠使用 WebView2 挂起，保留当前页面；唤醒按钮或快捷键继续原页面。工具栏不新增 WebView、不修改网站内容。

验证：30 项前端单元测试、13 项界面测试、18 项 Rust 测试、Clippy 与格式检查通过；另显式运行 5 项原生流程测试，覆盖托盘关闭/任务栏兜底、真实退出进程、真实 IPC 网页加载/缩放/挂起/唤醒/关闭、独立程序启动重连以及既有 WebView2/捕获/贴边流程。修复前的原生测试分别复现“主窗口被销毁”和“IPC 创建网页超时”，修复后通过。

范围：自动启动基于已捕获窗口的有效 EXE 路径，尚未提供自定义启动参数或商店应用激活配置。休眠保留页面内存状态，未承诺固定的内存节省比例；工具条目前采用深色样式。

分支：`codex/runtime-and-island`。
修改前回退点：`v1.0.13-before-runtime-fixes`。
发布标签：`v1.0.14`（本地 Git）。
