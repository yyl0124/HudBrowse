# HudBrowse 1.0.15

- 修复灵动岛拖拽排序：改为应用内指针拖拽，停止使用会进入 Windows 原生文件拖放流程的 HTML5 拖拽。主窗口关闭不使用的文件拖放接管。
- 修复滚轮浏览：移除会吞掉小幅位移的滚动吸附，统一处理横向、纵向滚轮及触控板输入。
- 增加左右浏览按钮，鼠标也可以逐组查看三个之外的图标；触摸仍可左右滑动。
- 支持拖拽到轨道边缘后自动滚动；按 Escape 或移出轨道松开取消排序，拖动结束不误打开目标。

定位证据：修复前，真实 WebView2 的 OS 鼠标拖拽只触发 dragstart，排序未变化；关闭文件拖放接管后能收到 dragover，但 drop 仍未稳定到达。浏览器中 8px 滚轮输入也被吸回 scrollLeft=0。修复后原生拖拽与细粒度滚轮回归通过。

验证：30 项前端单元测试、15 项界面测试，以及加载生产前端构建的真实 Windows 鼠标输入测试通过；TypeScript、Vite、Clippy、格式检查和 Windows NSIS 打包通过。原生输入测试覆盖岛内排序、拖拽不误点击、小幅滚轮、点击浏览按钮及打开新显示的目标。
