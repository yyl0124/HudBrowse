# HudBrowse 1.0.10

## 更新

- 使用用户提供的 `public/bitbug_favicon.ico`，两个原生 ICO 文件均按字节原样复制。运行时图标为 64×64，编译数据与源图逐像素一致。
- 确认了此前图标模糊的一条实际原因：Tauri 1.x 取 ICO 第一帧作为运行时图标，旧生成文件第一帧为 16×16。新 ICO 为用户制作的单帧 64×64。
- 收起为灵动岛、展开工作台增加收拢与展开淡入动效。原生尺寸切换安排在界面透明阶段，避免逐帧修改窗口尺寸导致裁剪区域不同步。切换时阻止重复操作，失败后恢复界面；支持系统减少动态效果设置。
- 灵动岛自动支持左右贴边收纳，独立于目标窗口的全局默认配置。鼠标移开 280ms 后滑入边缘，留下 36 个逻辑像素宽的半圆；悬停半圆时滑出，拖离边缘后解除吸附。上下边缘不收纳。
- 展开工作台、关闭到托盘和退出时清理贴边监视，丢弃未执行的位置更新，恢复主窗口到屏幕工作区。

## 验证

29 项前端单元测试、11 项端到端测试、17 项 Rust 单元测试、Clippy（-D warnings）和 1 项真实 WebView2 集成测试通过。新增覆盖普通/减少动态效果、反复切换、原生调用失败后的恢复、左右半圆宽度、DPI 取整、悬停反向移动，以及展开后无残留移动。生产构建和 NSIS 安装包生成成功。
