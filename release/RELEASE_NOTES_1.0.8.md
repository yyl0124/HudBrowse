# HudBrowse 1.0.8

- 采用用户提供的 314×314 小尺寸品牌图，更新前端、托盘、EXE 与安装包图标；ICO 内含 16、24、32、48、64、128、256px。
- 窗口显示时使用睁眼图标，隐藏时使用划线眼睛图标。
- 消除空/非空分类切换时主页面瞬间出现的滚动条，保留列表与详情滚动。
- 工作台和灵动岛 Logo 放大 24%，去掉图标内边距，不改变布局盒及其他元素行高。
- 详情区域增加按需出现、可点击的向下箭头，到底自动隐藏。
- 应用设置平铺为三列等宽卡片，小屏幕改为单列。

验证：29 项前端单元测试、9 项端到端测试、12 项 Rust 单元测试及 1 项真实 WebView2 集成测试通过；生产构建及 NSIS 打包成功。已检查工作台、灵动岛和应用设置截图。

Git 分支：`codex/icon-layout-fixes`。修改前回退标签：`v1.0.7-before-usability-fixes`（802090d）。发布标签：`v1.0.8`。未配置远程仓库，版本保存在本地。

直接运行 `HudBrowse_1.0.8_x64.exe`，或使用 `HudBrowse_1.0.8_x64-setup.exe` 安装。测试前先从托盘退出旧版本。真实任务栏的显示效果仍需在用户的 DPI 与主题环境下验收。
