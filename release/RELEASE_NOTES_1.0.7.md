# HudBrowse 1.0.7

## 品牌与文案

- 使用最新的 `public/hudbrowse.png`，同步标题栏、浏览器页签、系统托盘、EXE 和安装包图标。桌面 ICO 包含 16–256px 共七种尺寸。
- 首页宣传语改为“常用窗口，随手即达”。
- 去掉英文装饰性标签、标题旁斜杠和列表底部“目标 / 独立配置”统计；必要的设置、程序位置等标签使用中文。

## 操作动效

- 全部、网址、桌面筛选，以及主导航和设置分类使用滑动高亮。
- 筛选、排序、选中详情及页面切换增加短暂的淡入与位移。列表仅处理可视条目，后台轮询不会重复播放动效。
- 按钮按压、开关、主题切换、图标加载、下拉框、表单反馈及弹窗加入相应过渡。
- 弹窗和下拉框关闭时淡出；退出中的内容不再接收鼠标或键盘事件。捕获窗口进入编辑表单时，旧弹窗退出不会抢走焦点。
- 遵循系统“减少动态效果”设置，快速连续操作会切换到最后一次选择。

## 验证与版本管理

- 29 项前端单元测试、8 项端到端测试、12 项 Rust 单元测试和真实 WebView2 集成测试通过。
- 已检查普通、窄窗口、明暗主题和灵动岛截图；原生 PNG 与最新源图缩放结果逐像素一致。
- 修复前回退标签为 `v1.0.6-before-polish`（`b454822`），包含用户提供的最新源图。
- 本次在 `codex/brand-motion-polish` 分支完成，发布标签为 `v1.0.7`。未配置远程仓库，版本保存在本地 Git。

直接运行 `HudBrowse_1.0.7_x64.exe`，或使用 `HudBrowse_1.0.7_x64-setup.exe` 安装。测试前请先从托盘退出旧版本。
