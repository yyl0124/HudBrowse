# HudBrowse 1.0.16

- 灵动岛移除“活跃”文字，完整显示四个图标容器，保留拖拽排序、滚轮和左右按钮浏览。
- 新增场景：在捕获窗口与添加网址之间进入，按勾选顺序组合已有目标；快捷键和灵动岛都能执行。
- 场景复用成员的已有参数和设置，组合图标随成员变化；编辑中展示启动顺序。
- 状态统一规则：全隐藏/未启动时依次唤醒，全显示时全部隐藏；混合时按多数统一，平票显示。例如一个隐藏、两个显示，再次触发后三个全部显示。
- 成员启动失败仍继续执行后续成员，并提示失败原因。统一隐藏不会启动未运行程序。
- 删除场景保留成员，删除成员自动清理场景引用；空场景可重新编辑。

验证：44 项前端单元测试、18 项界面测试、18 项 Rust 常规测试通过；真实 WebView2 四图标/拖拽/滚轮/按钮测试及网页与捕获窗口幂等隐藏测试通过。TypeScript、Vite、Clippy、格式检查及 NSIS 发布构建通过。

发布标签：`v1.0.16`（本地 Git）。
