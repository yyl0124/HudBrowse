# HudBrowse 1.0.13

- 设置 → 应用增加“关闭时最小化到托盘”开关：开启后保持后台运行，关闭后点击叉号直接退出程序。
- 主界面、灵动岛与 Alt+F4 使用统一原生关闭逻辑。退出前保存会话并恢复捕获窗口。
- 设置自动保存并在重启后生效，恢复默认设置会重新开启托盘常驻。未显示托盘图标时，常驻模式最小化到任务栏，设置页会显示对应说明。
- 应用设置改为两列等宽布局，窄屏单列。

验证：30 项前端单元测试、12 项界面测试、18 项 Rust 测试、格式检查与 Clippy 通过，Windows 发布构建及 NSIS 打包成功。界面测试使用原生 IPC 替身验证偏好同步；本次未运行真实 WebView2 集成测试。
