# HudBrowse 1.0.17

- 修复启动 HudBrowse 时自动拉起捕获程序：会话恢复仅处理网页，桌面目标只连接已运行窗口。用户点击目标、触发快捷键或执行场景时仍可主动启动程序。
- 修复退出后捕获窗口消失：释放捕获时还原原始样式、透明度和置顶等设置，恢复被隐藏窗口的可见性，不再重放捕获瞬间的隐藏状态。
- 主动启动桌面程序改由 Windows 桌面 Shell 执行，不再使用 HudBrowse 的子进程启动方式。实际退出测试验证目标程序仍运行且窗口可见。
- 设置文案调整为“恢复上次可见网页”。
- “添加场景”改用单个图层图标，缩小图标占位、图文间距和横向内边距。

根因：1.0.14 引入主动唤醒后，会话恢复复用了同一个 show 路径；新程序的窗口也可能在首次显示前被记为隐藏，退出时恢复旧快照便使窗口消失。原先直接 spawn 还会将进程挂在 HudBrowse 的进程树下。

验证：46 项前端单元测试、19 项发布构建界面测试、18 项 Rust 常规测试通过。真实原生测试覆盖程序重连与独立启动、网页/捕获控制，以及 HudBrowse 退出后的目标进程存活与可见性（显示和隐藏两种状态，含中文/空格路径）。TypeScript、Vite、Clippy、格式检查和 NSIS 构建通过。
