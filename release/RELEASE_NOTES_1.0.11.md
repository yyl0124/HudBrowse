# HudBrowse 1.0.11

- 优化灵动岛左右贴边识别：除了靠近屏幕边缘，也识别已经跨出边缘的情况。松开并移开鼠标后从当前位置平滑收纳到只剩半圆，不先弹回屏幕内；拖动中不吸附。
- 灵动岛的捕获窗口与网页图标放大到 36px，移除双层圆框、底色、图片内边距，保留文字替代及按钮状态语义。
- 核验托盘资源：PNG 与用户 ICO 同为 64×64，解码像素完全相同，没有资源混用或小图放大的问题。托盘显示面积小于任务栏，复杂图样缩小时细节更难分辨，按用户要求保留原图。

验证：29 项前端单元测试、11 项界面测试、18 项 Rust 单元测试、Clippy（-D warnings）及 1 项真实 WebView2 集成测试通过。新增覆盖左右两侧不同遮挡比例、负屏幕坐标与 DPI；真实窗口分别拖出约 20%、50%、85% 后均收纳到半圆。

分支：`codex/island-edge-tuning`。
回退标签：`v1.0.10-before-edge-tuning`。
发布标签：`v1.0.11`。版本保存在本地 Git。

测试前先从托盘退出旧版本，再运行 `HudBrowse_1.0.11_x64.exe` 或安装 `HudBrowse_1.0.11_x64-setup.exe`。
