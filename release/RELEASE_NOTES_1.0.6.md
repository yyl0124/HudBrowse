# HudBrowse 1.0.6

## 本次修复

- 标题栏与主体使用同一个代码生成的 SVG 轮廓，内凹圆角连接；原生窗口裁剪使用同一组点并补偿客户区偏移与 DPI，修复图标、关闭按钮被裁掉和灵动岛残边。
- 标题栏全部非按钮区域支持拖动；保留原生窗口控制。
- 恢复贴边隐藏/展开的 220ms 缓动，支持移动中反向展开，停止监视恢复原位置。
- 分类、排序和编辑表单全部改为自定义下拉框，支持键盘导航与 Escape 关闭。
- 捕获列表、目标列表、详情及灵动岛显示真实程序图标；网站支持 favicon 和网页声明的图标，不使用第三方图标服务。无法取得图标时显示名称首字。
- 三点菜单改为直接删除，并保留删除确认。网页右键菜单保留刷新、前进后退与站点数据清理。
- 隐藏 TARGET DETAILS 滚动条，保留滚轮和触控板滚动。
- 修复监视线程身份检查读取窗口标题时可能与界面线程互相等待的问题。

## 验证

- 29 项前端单元测试、6 项 Playwright 端到端流程通过。
- 12 项 Rust 单元测试及显式 WebView2 原生集成测试通过。
- `cargo clippy --all-targets -- -D warnings`、前端生产构建及 NSIS 发布构建通过。
- 检查普通/灵动岛截图，以及当前桌面 DPI 下标题栏两端、接缝和透明区域的真实 Win32 裁剪。
- 多显示器混合 DPI 和不同系统缩放比例仍需对应硬件环境测试。

## 使用与回退

直接运行 `HudBrowse_1.0.6_x64.exe`；需要安装时使用 `HudBrowse_1.0.6_x64-setup.exe`。测试前先从托盘退出旧版本。
